- Team formation and collaboration.

- Real-time notifications.

**Software Testing & Quality Assurance**

- Collected and analyzed UAT feedback from students and supervisors across multiple universities.
- Documented technical requirements and testing activities.

**Project Achievements**

- Applied Agile/Scrum methodology across 4 sprints.
- Delivered the MVP within 8 weeks.
- Achieved a 100% pass rate on core test cases.

**Project Period:** October 2025 – January 2026.
